DEA installation and verification (06 Nov 2026)

1. Copy/use the entire ado/ directory as one matched package.
   It contains 74 ado/help/do files, including _dea_recovery.ado,
   _dea_weak_bound.ado and the matching common simplex/adapters.
   Do not install only dea.ado or mix helpers from an earlier release.
2. Start a fresh Stata 16+ session, or save your data and then use clear all.
   Mata structures changed during earlier development. Hot replacement of
   arbitrary older loaded packages is not an ABI compatibility guarantee.
3. Point adopath at this repository's absolute ado path:
       adopath ++ "/absolute/path/to/DEA-Stata/ado"
       which dea
       findfile _dea_recovery.ado
       findfile _dea_simplex.ado
       findfile _dea_weak_bound.ado
       findfile dea.sthlp
   Confirm that each path belongs to the same package directory.
   dea should report version 2.0.73; simplex source is 2.0.25.
   The LP adapter is 0.4.9; MILP is 1.2.7. Simplex readiness is 16,
   and adapter readiness is 9. Copy the complete matched package.
4. Run the self-contained example below in an empty session:
       clear
       input id x y
       1 1 1
       2 2 4
       3 4 2
       end
       dea x=y, dmu(id) engine(simplex) stage(2) recoverylog gen(score)
       matrix list r(recovery_stats)
       matrix list r(recovery_log)
       assert r(recovery_stats)[1,1]==6
       assert rowsof(r(recovery_log))==6
       assert colsof(r(recovery_log))==25
       assert score<.
       matrix list r(stage_linkage)
       assert colsof(r(stage_linkage))==30
       assert r(n_stage_link_adjusted)==0
       help dea
5. recoverylog is OFF by default. Minimum abbreviation is recoveryl.
   Detail is capped at min(c(matsize),10000); counts include omitted rows.
   Native-only runs have zero counts and no recovery_log matrix.
   Unsupported model combinations are rejected, not silently ignored.
   Existing result-variable replacement and saving() rules still apply.
6. Reproduce the dedicated contract/byte-parity test from tests/:
       python test_recoverylog.py --stata /path/to/stata-mp \
         --output /new/output/directory --baseline-ado /frozen/compatible/ado \
         --fixture fixtures/weak_units2.csv
   Requires NumPy/SciPy and licensed Stata 16+. Faults run in private copies.
   The synthetic units2 weak-disposal recovery example is included in tests/fixtures/.

Exact duplicate recovery (simplex 2.0.22, contract 0.4.6, MILP 1.2.4):

presence checks replace compatible old Mata-only engines and detect missing
duplicate helpers at the DEA, LP, weak-disposal and MILP entry points.
For a fully cached older package, save data and use clear all or a fresh session

At the DEA, LP, MILP and weak-disposal entry points, stale or incomplete simplex
libraries are rejected after attempted reload with
r(498) and a matched-package installation message. This detects version/helper
inconsistency; it is not a cryptographic check of manually edited code.
